# Changesets

Chaque modification d'un paquet publié s'accompagne d'un fichier de ce dossier, créé par
`npx changeset` : quels paquets changent, de quel type (correctif, ajout, changement cassant), et
une phrase pour le journal des versions. Le workflow « Publication » s'en sert pour calculer les
versions et publier sur npm ; voir le README racine.
